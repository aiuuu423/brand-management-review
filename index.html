第1章｜品牌管理概述

1.1 品牌由来与四种定义视角（P33—45）

品牌一词brand源于古挪威语brandr，含义为“打上烙印”；由标记家畜和财产，发展到工匠标记生产者、产地，以及质量担保与法律保护。

符号说：品牌是识别并区别产品或服务的名称、标记、符号、设计及其组合。代表表述包括AMA、科特勒、Upshaw；重点在“识别与区分”。

综合说：奥格威强调属性、名称、包装、价格、历史、声誉、广告风格的无形组合。重点在整体印象。

关系说：从品牌与消费者之间的联系理解品牌，重点在消费者认同、信任及持续关系。图片原文见逐页核对。

资源说：品牌是可以经营、增值的资源和资本，体现为超越有形产品的无形价值。

课件教材综合定义：品牌是给拥有者带来溢价、产生增值的无形资产；载体是区分竞争产品或劳务的名称、术语、象征、记号、设计及其组合；增值源泉是消费者心中关于载体的印象。

1.2 品牌内涵、核心价值与外延（P46—66）

六层内涵：属性、利益、价值、文化、个性、使用者。属性是性能、质量、技术、定价等特征；利益是这些属性带来的功能性或情感性好处；价值是品牌所追求和承诺的价值；文化是精神背景；个性是人格化特征；使用者是品牌所体现的典型用户形象。

例：奔驰“技术精良”是属性，“安全、减少修理成本”是利益，“高性能、安全、声望”是价值。不能把属性与利益写成同一层。

金字塔归并：底层“属性＋利益”对应功能定位；中层“文化＋个性＋用户”对应识别差异；顶层“价值”对应价值承诺。消费者认知通常自下而上；企业塑造应以核心价值自上而下统率。

核心价值：品牌资产的主体部分，使消费者记住利益点与个性，驱动偏爱；包括功能性利益价值、情感性价值、自我表现型（社会型）价值。统率定位、设计、传播和体验；品牌差异既可有形理性，也可无形、象征、情感。

产品五层在本章也出现：核心利益、一般产品、期望产品、延伸产品、潜在产品。本章“延伸产品层”与第10章“附加产品”应结合语境理解。

品牌外延七项：名称、标识、标志物、标准字、标准色、标准包装、广告曲。标识分文字、图案、图文；标志物是具象、常取材于现实生活的特殊图案标识；标准包装可成为认购依据；广告曲形成声音记忆。

1.3 品牌分类：七套标准分别背（P68—94）

按影响力：地区、国内、国际品牌；判断依据是公众认知及影响辐射范围。

按品牌化对象：产品、服务、组织、个人、事件、目的地品牌。产品品牌包括消费品与工业品；服务品牌包括专业型与生产型售后服务；目的地包括城市与国家。

国家品牌指数相关维度：出口、治理、文化、人民、旅游、移民与投资（P82）。

按市场地位：领导者、挑战者、追随者、补缺者。领导者占据领先份额；挑战者争取更大份额；追随者更多模仿；补缺者专注被忽视的利基市场。

按生命周期：新品牌、上升品牌、领导品牌、衰退品牌。新品牌扩大知名度；上升品牌强化形象和认同；成熟领导品牌通过活化与新产品保持偏好；衰退品牌可改进产品、拓展新市场与产品、降低成本和提高营销效率。

按生产经营环节：制造商品牌、经销商品牌。由谁建立品牌是判断核心，不是单看谁生产产品。

按来源：自有、外来、嫁接品牌。外来品牌通过特许经营、兼并或收购取得；嫁接品牌由合资合作形成。

按原创性和延伸性：主品牌、副品牌、副副品牌。

1.4 品牌的作用（P102—117）

对消费者五项：识别产品来源、减少购买风险、降低搜寻成本、质量信号、象征功能。

六种购买风险：功能、身体、财务、社交、心理、时间风险。社交是他人评价带来的尴尬；心理是自身内疚或不安；时间风险包括重新寻找替代品的机会成本。

搜寻成本有内在“不必多思”和外在“不必到处搜寻”两个方面。

对企业六项：区隔、保护产品特色、塑造企业形象、降低企业成本、获取竞争优势、溢价。

对国家：国家形象的代表；与国民经济发展存在相关性。中国品牌日为每年5月10日；课件强调制造向创造、速度向质量、产品向品牌转变。

1.5 品牌管理内涵与完整流程（P119—136）

主体：责任明确的品牌管理者；目的：培育品牌资产；中心：消费者；内容：战略决策与策略执行。特点：系统性、全方位性、长期性。

品牌资产解释有品牌与无品牌产品在营销结果上的差异，不能只用商标注册或一次广告曝光衡量。

必背①凯勒四步骤：识别和确立品牌定位与价值 → 规划并执行品牌营销活动 → 评估和诠释品牌绩效 → 提升和维系品牌资产。

第一步关键概念：心智地图、竞争性参照框架、共同点POP、差异点POD、核心品牌联想、品牌箴言/精髓。共同点保证基本资格和减少劣势，差异点提供选择理由。

第二步：品牌元素组合匹配、营销活动整合、次级联想。次级联想借助公司、原产国、渠道、其他品牌等实体间接建立。

第三步：品牌价值链、品牌审计、品牌追踪、品牌资产管理系统；第四步：品牌—产品矩阵、组合与架构、延伸、强化和激活、跨地域文化管理。

必背②切纳托尼八步骤：品牌展望 → 组织文化 → 品牌目标 → 审查品牌环境 → 品牌本质 → 内部实施手段 → 寻找品牌资源 → 品牌评估。

必背③戴维斯四阶段十一步：制定愿景〔品牌愿景要素〕；描绘图景〔确定形象、制定品牌契约、建立基于品牌的顾客模型〕；制定资产管理战略〔定位、延伸、宣传定位、渠道影响最大化、溢价定价〕；支持资产管理的文化〔衡量品牌投资回报、建立基于品牌的文化〕。

必背④余明阳、姜炜五步骤：内部审视 → 外部环境分析 → SWOT分析 → 构建战略规划 → 实施品牌战略。课件“SWTO”为字母顺序笔误。

必背⑤周志民四阶段十一步：规划〔品牌识别、品牌符号〕；传播〔品牌定位、品牌体验、整合品牌传播〕；提升〔品牌延伸与授权、品牌组合、品牌更新、品牌国际化〕；评估〔品牌资产评估、品牌保护〕。答题时按这一作者的课件顺序写，不能用凯勒的顺序替换。

品牌管理十二项内容：方向与目标、管理组织、品牌决策、定位、设计、推广、延伸、组合、危机、更新、国际化、资产评估与管理。

品牌资产四项基本原则：品牌活动的附加价值导致不同业绩；培育方式多样；资产为解释策略和评估价值提供共同标准；价值可体现为收益增加、成本下降或两者兼有。

审计、追踪与价值链的区别：审计是全面诊断健康和资产来源；追踪是连续监测变化；价值链追踪价值创造及营销投入的财务效果；评估系统为短期策略与长期战略提供及时、准确、可追溯的信息。

1.6 管理组织、案例与练习（P138—158）

五种组织形式：业主负责制、职能管理制、品牌经理制、品类经理制、品牌管理委员会。业主制适合规模小、人员少的创业企业，决策集中但依赖业主；职能制专业分工但易割裂；品牌经理制对单品牌负责，责任明晰但可能品牌间内耗；品类经理制对多品牌构成的产品类别及盈利负责，有利于品类协调；委员会由高层和职能/品类负责人协调，统筹强但沟通成本高。优缺点为依据组织机制作的答题分析，非原文逐字引述。

桔子酒店关键词诉讼：关键词承载品牌识别、竞争优势和无形资产；分析法律保护与消费者关系。

麦当劳：经营理念、行为识别与视觉识别共同支持品牌价值，结合QSCV及儿童家庭顾客分析忠诚。

湾仔码头：创始人故事、高端定位、质量保证、合作与国际影响。

汇报案例池：SHEIN、优衣库/HM/Zara、两所香港高校、小米汽车、黑神话、传音、抖音、瑞幸、医疗组织扩张、英伟达、BrandZ排行榜。用途是练习跨章节分析，而非背实时数值。

课件选择题答案：标志物＝B；视觉识别体系“标识”＝C；属性带来好处为“利益”＝A。判断题：品牌资产属于有形资产＝错；个性会随时代演进＝对；标志不会更新＝错。

第2章｜品牌定位与品牌个性

2.1 定位内涵、意义与原则（P12—17）

定位是在目标消费者心智中建立相对于竞争品牌的清晰位置；重点是消费者如何理解，而不只是企业口号。

五项意义：便于记住信息、确立个性、作为传播基础、提供购买理由、占领市场的前提。

四原则：心智主导、差异化、稳定性、简明性。

2.2 定位过程与市场选择（P19—24）

五环节：市场分析 → 企业内部条件分析 → 市场细分 → 确定目标市场 → 具体定位。

市场分析包括竞争者、消费者；内部分析包括战略、产品、服务水平、企业形象、规模、渠道、人力资源。

细分依据四类：地理、人口、心理、行为。人口包括年龄、性别、收入、家庭规模、教育、宗教、职业；行为包括了解、态度、使用及反应；心理可按生活方式与信念差异划分。细分要求是具体明确、具有潜力且可进入。

七步细分法：估计顾客需求 → 分析需求 → 划分细分市场 → 命名细分市场 → 明确特点 → 评估盈利水平 → 确定细分市场。

评估细分市场：规模、内部结构吸引力、企业资源条件。

进入方式：集中进入（集中一个目标）；有选择的专门化（几个联系较少的市场）；专门化进入（课件举专门生产一种产品服务多类客户）；无差异进入（强调共同需求）；差异进入（针对不同目标需求，成本较高）。图片中的市场细分标准另见补充。

具体定位五步：分析目标顾客价值观 → 提炼核心价值 → 建立优秀联想 → 有效传递定位理念 → 强化理念。

2.3 定位策略与重定位（P26—52）

四个定位角度：产品、目标消费者、竞争者、品牌识别。产品角度为属性、利益、类别、价格；消费者角度为消费群体、情景/场景、情感；竞争者角度为首席、比附、空当、对比；识别角度为个性、文化。利益定位根据产品解决问题程度和提供的主要功能性利益定位，如柔顺、去屑、健康亮泽，风险是可能加剧品牌竞争。

产品属性定位：以独特产品特征区隔，如奥妮“植物一派”；注意容易被模仿。

类别定位：与已有普通类别区隔，建立另一品类认知，如七喜“非可乐”；关键是消费者是否接受类别，过强的品类绑定也会限制延伸。价格定位分高、中、低，易吸引相应人群，但上下延伸可能冲击旧形象。

消费群体定位：直接表明服务某类人群，如太太口服液、儿童感冒药。场景定位：将品牌与特定时间、环境、条件联系，如白加黑；关键是让场景有必要使用，以及建立品牌与场景的固定联想。

情感定位：借情感体验建立认同，如雕牌；其基础是消费者的情感需求。

竞争者角度四项：首席、比附、空当、对比定位。首席强调某一方面领先；比附借知名品牌影响力；空当寻找未被满足的需求；对比通过客观比较确定位置。

比附定位三种：甘居第二（安飞士）、攀龙附凤（“塞外茅台”）、高级俱乐部策略（强调属于少数高声望品牌群体）。

空当可从时间、年龄、性别、使用量寻找；不是只要市场无人进入就有价值，还需存在可满足的真实需求。

品牌识别角度：品牌个性定位、品牌文化定位。前者人格化；文化定位分以民族精神为代表的历史文化、以企业经营理念为代表的现代文化。

重定位八时机：原定位老化、错误、模糊、过窄；竞争模仿；遭遇变故；战略转移；发现更有价值定位。四步：确定原因 → 调查分析与形势评估 → 分析目标消费者、选择最有竞争优势的定位 → 传播并巩固新定位。

2.4 品牌个性：特征、维度、来源和塑造（P54—63）

定义：与品牌相联系的一整套人格化特征；四特征：人格化、独特和不易模仿、持续和一致、随时代演进。

美国五维：纯真、刺激、称职、教养、强韧（量表行标题也写“强壮”）。结构为：纯真〔纯朴、诚实、有益、愉悦〕；刺激〔大胆、有朝气、富于想象、新颖〕；称职〔信赖、聪明、成功〕；教养〔上层阶级、迷人〕；强韧〔户外、强韧〕。

中国五维：仁、智、勇、乐、雅（课件正文列“仁、智、乐、勇、雅”，同一组维度）。仁包括诚家、和、仁义、朴、俭；智包括稳谨、专业、创新；勇包括勇德、勇形；乐包括群乐、独乐；雅包括现代之雅、传统之雅。课件表中的“检”结合词义按“俭”理解。

第3章｜品牌设计

3.1 品牌要素总标准（P9）

五标准：可记忆性（识别、回忆）、有含义性（描述、说服、趣味、联想）、可转换性（产品门类、地域文化）、可适应性（灵活、更新）、可保护性（法律、竞争）。

课后题用“可转移性”，与表中“可转换性”结合理解为跨品类及跨地域文化使用的能力；不能与可更新的适应性混为一谈。

3.2 名称设计：六原则、三套来源、十步程序（P11—20）

六原则：简洁明快、语音朗朗上口、正面联想、个性独特、适应性、合法性。

按品牌特性：功能性、情感性、中性名称。

按出处：人名、地名（P15图片）、动植物、自创。动植物命名须考虑与产品内在联系、美好象征及跨文化歧义。

按文字类型：汉字、拼音、外语、数字；数字包括纯数字与数字文字组合。

十步：成立命名工作小组 → 前期调查 → 选命名策略 → 动脑会议 → 名称联想 → 法律审查 → 语言审查 → 内部筛选 → 目标人群测试 → 确定名称。

3.3 标识、标准字、标准色、标志物（P22—40）

标识是视觉识别核心，承载可识别的图形、字体、色彩等；分文字、图案、图文标识。图案可分形象与抽象；图文可将名称字母或部分转成图案。不能把所有视觉识别都缩成一个图案。

标识五原则：简洁鲜明、独特新颖、适应性、优美精致、合理合法；四流程：调研分析、要素挖掘、设计开发、标识修正。标识类型图片见P23—25。

标准字五种：企业名称、品牌名称、字体标识、活动、标题标准字。三原则：易辨、艺术、传达；三方法：书法标准字体、装饰字体、英文设计；五程序：调查研究、基本造型、校正视觉误差、统一字体形象、排列。

标准色四原则：突出风格反映理念、制造差别体现个性、符合消费心理、适应国际化；四程序：理念设计、色彩设计、色彩管理、效果测试。

色彩心理效应：颜色可以传递情感并影响精神、情绪和行为；课件以红色的热情、活力与冲击为例。心理联想与民族文化含义应共同考虑。

色彩的民族特性：课件P33表列24个国家或地区的喜爱与禁忌；完整表保留于逐页核对。复习重点是同色在不同文化可能产生不同联想，不能套用单一市场经验；表内概括也不能代表每位当地消费者。

标志物两套分类：卡通形象/真实人物；唯一/系列标志物。真实人物形象不等于必须聘请现实明星。

标志物四步：精确细分与定位 → 创造性塑造角色 → 多方位科学市场测试 → 积极有效宣传。P38—39为七喜FIDO DIDO与长安“奔哥奔妹”图例。

第4章｜品牌传播

4.1 传播概述与新媒体环境（P9—18）

品牌传播以核心价值为原则，在整体识别框架下，选择广告、公关、销售、人际等方式，将信息传给目标消费者，形成认知、认同与独特形象。四特点：信息聚合、受众目标、媒介多元、操作系统；三意义：强化认知、满足情感、建立长期关系。

必背信息模型：发送者 → 编码 → 信息/媒介 → 解码 → 接收者；接收者反应经反馈回到发送者，噪声可干扰整个过程。

新环境包括技术进步、消费者权力增长、传统媒体碎片化、互动移动营销、渠道变化、产业竞争、全球化、社会环保关注与经济变化。

消费者更易获取信息、购买多类商品、与企业及其他消费者互动；企业更易发布、分销、收集信息、双向沟通、个性化服务与改善内外职能。

4.2 自媒体：企业内刊、官网、社会化媒体（P20—42）

企业内刊兼有内部沟通凝聚力与外部形象传播功能；方式为内部导向、内外兼顾（一刊两职/内外分离）、外部导向；方法为定位内外明确、内容突出企业个性、借网络扩大影响。

官网是消费者接触品牌信息并产生情绪与联想的渠道；分基本信息型、综合门户型、主题宣传型。方法：明确导入品牌形象、审美及趣味、鼓励参与。

社会化媒体给予用户参与空间，具有公开、互动、连通、社会性；内容发布主体常是用户。品牌传播三特点：软沟通、社会化价值、品牌用户共生；注意从“请消费者注意”转向“请注意消费者”。课件列YouTube、WhatsApp及百事微电影。

4.3 广告：作用、创意、媒介和策略（P44—61）

五作用：建立忠诚、快速提高知名度、正面品质认知、提供联想空间、树立个性。

广告主题创意：识别产品优点 → 开发并评估诉求 → 选择独特营销建议 → 表述信息。创意与媒介选择常同步。

六媒介比较：电视覆盖广、有声光动态但绝对/制作成本高且干扰大；广播成本低、受众细分但只有听觉且易逝；杂志细分、可重读但前置期长；报纸时效强、本地覆盖但生命短、展示弱；户外重复曝光但受地域与空间限制；交互媒介参与强、信息弹性大但需处理技术、创意及测量限制。

媒介执行要点：电视突出目标和品牌标识；广播早提品牌、重复利益、口语清晰；纸媒利益显著易读；户外选择人流与画面冲击；互动信息有趣并更新。

选择六因素：产品性质、消费者媒介习惯、传播范围、影响力、速度、费用。

组合三原则：视觉＋听觉；瞬间＋长效；大众＋促销媒介。

五类广告策略：名人代言、理性诉求、情感诉求、影视植入、文化意蕴。理性诉求以属性功能说服，包括直接陈述、引用数据、对比；情感诉求针对心理社会象征需求，激发共鸣。植入融入媒介情节；文化意蕴连接价值、期待和荣誉联想。

4.4 公关和销售促进（P62—86）

公关正确处理企业与公众的关系，借第三方信息和公共活动建立形象；三价值：提高知名度、树立形象、澄清危机。

活动方式五类：宣传性（新闻式/广告式）、赞助性（文化教育体育等）、服务性（指导培训维修）、征询性（咨询、问卷、民意测验、热线、交流、征名）、危机公关。征询重在收集反馈并形成互动联系。

四工作程序：调查 → 计划 → 实施 → 检测。P73“如何有效开展赞助”是课堂讨论页，未列标准答案；可按目标公众匹配、品牌价值一致、接触点设计、效果检验作答（这些是应用建议）。

销售促进对象三类：消费者、经销商、销售员。

促销作用：短期吸引品牌转换者，通过购买人数、平均购买量、重复购买率增加销量；部分长期活动也可巩固形象与关系。不能把促销仅理解为降价。

消费者八方式：代价券（通常称优惠券）、价格折扣、商业贴花、样品、奖品、附加赠送、竞赛抽奖、POP买点促销。

经销商六方式：广告技术合作、业务会议与展览、现场演示、交易推广、竞赛、企业刊物。

销售员：培训与竞赛；培训包括课堂、讨论、案例、角色扮演。

决策三步：建立目标 → 选择方式 → 制定方案。选择看目标、产品类型、竞争地位、预算；方案定范围、诱因量、传播媒介、参与条件、时间、费用。

4.5 整合营销传播IMC（P88—94）

核心是以消费者为中心协调各种接触点与工具，使品牌信息一致、连续、互动，而非机械复制同一广告。

五特点：目标性、互动交流性、统一性、连续性、动态性。

七层次：认知整合 → 形象整合 → 功能整合 → 协调整合 → 基于消费者 → 基于风险共担者 → 关系管理整合。

六方法：消费者资料库 → 研究消费者 → 接触管理 → 发展沟通策略 → 创新营销工具 → 组合传播手段。

案例、必背清单与易错点

汉堡王“听话的小鸡”：互动体验引发兴趣；贝尔电话广告：情感诉求；百事微电影：社会化传播；可口可乐中毒、克莱斯勒：危机公关；联想：口号、IBM、冬奥与背书整合。董宇辉“小作文”、交个朋友假货为危机处置练习。

必背：传播模型、各传播方式、自媒体方法、广告五作用/创意流程/六媒介/六因素/三组合原则/五策略、公关五形式/四程序、促销三对象及各方式/三决策步骤、IMC五特点/七层次/六方法。

易错①自媒体不等于只有社交账号，企业内刊与官网也在本章范围内。

易错②广告、公关、促销的主要机制不同：付费信息、公众关系、短期激励不能相互替代。

易错③高曝光不等于有效解码，更不等于忠诚或销售；需检验反馈和接触质量。

易错④IMC并非渠道越多越好，也不只是视觉统一，还包括组织协同与关系管理。

易错⑤经销商激励不能直接当消费者促销；POP是销售现场触点。

第5章｜品牌组合

5.1 概念、衡量标准与战略框架（P18—29）

品牌组合是企业所有品牌的有机组成方式，涉及品牌数量、层级、特征及关系；不同品牌服务不同目标市场。

三衡量标准：宽度＝拥有品牌数量；长度＝子品牌/辅助品牌数量及使用；密度＝品牌之间关联度。不能套用产品组合“深度”替换课件术语。

五方面重要性：企业资源、企业效益、企业成长、杠杆作用、一致性。

艾克六方面框架：品牌组合、定义产品时扮演的角色、品牌范围、组合角色、组合结构、组合图标。

定义产品的九种角色或要素：主品牌、担保/背书品牌、子品牌、描述性品牌、产品品牌、保护伞品牌、驱动角色、品牌化差异点、品牌联合。主品牌是基本参照；担保品牌提供可信度；子品牌突出特性/细分市场；驱动角色影响购买；差异点可为特性、成分、服务或活动。

品牌范围是品类、子类别和市场上的跨度与边界，随发展动态变化。

组合战略五角色：战略品牌、品牌化活力点、银弹品牌、侧翼品牌、现金牛品牌。战略品牌包括当前实力型、未来实力型、关键品牌；活力点通过产品/促销/赞助/项目激活；银弹改善其他品牌形象；侧翼保护战略品牌；现金牛提供稳定回报。

三结构：横向（并行品牌）、纵向（同一产品的多层品牌描述）、联合（跨企业合作）。

组合图标包括标志、包装、产品设计、符号、布局、广告语；三功能：说明相对驱动位置、区分品牌/系列、直观展示结构。

5.2 四类组合战略：定义、利弊、条件（P31—65）

单一品牌：全部产品用同一品牌。优点为缩短新产品投入期、降低宣传促销费用、增强企业知名度形象；缺点为忽视市场差异、风险集中、延伸稀释或跷跷板。条件为已有信誉，以及质量、价格、目标市场和形象定位具有一致性。

多品牌：同时经营多个相对独立品牌。类型为一种产品多品牌、一类产品多品牌、不同类产品多品牌。优点为适应细分、扩大份额、突出特性、分散风险、合理内部竞争；缺点为核心价值模糊、管理难、成本高、资源分散。

多品牌六条件：财力、适合的行业/产品、细分容量、独特卖点、严格区隔且协同、差异化营销广告。

主副品牌：主品牌相同、另加副品牌，常为“企业＋事业＋产品/服务”形式。优点为降低费用增强促销、突出个性、反哺主品牌；缺点为副品牌喧宾夺主、仍有风险株连。条件为企业知名度、适合行业、传播主品牌为核心、副品牌直观表达优势。

品牌联合：两个或更多现有品牌合作。优点为互补、降促销费用、提升资产；风险为形象不一致、危机株连、协调破坏、合作结束仍被误认为持续。

四联合类型：认知型（相互展示顾客群）；价值认可型（核心特性价值一致、共同创造价值，包括专业品牌互补及与有影响力组织合作）；元素组成型（成分品牌与最终产品，如Intel）；能力互补型（各方专业优势开发新产品）。

联合五条件：选适合类型、品类关联、资源互补、名称清晰简练、权责界定。

5.3 三类组合分析工具（P67—73）

BCG矩阵：纵轴市场增长率，横轴相对市场份额＝本品牌份额÷主要/最大竞争者份额（答题注明比较对象）。问题〔高增长低份额〕；明星〔高高〕；现金牛〔低增长高份额〕；瘦狗〔低低〕。

BCG管理思路：问题选择性发展；明星支持投资；现金牛维护并提供资金；瘦狗评估收获/退出。课件图分界为增长率10%、相对份额1.0，属于该图设定，不是各行业固定标准。

GE矩阵：市场/行业吸引力×业务自身实力，双方各高中低三档，共九格；综合多因素评分，更细致地决定投资、选择性经营、收获/退出。

GE五步：定义因素 → 估测内外因素影响 → 评估重要性建立标准 → 标出业务单位 → 解释矩阵。

QPA：Quantified Portfolio Analysis，定量品牌组合分析；纵轴仍为市场/行业吸引力，另一轴改为相对品牌优势，并考虑内部品牌关系。用途是按市场/国家/产品/渠道排序，优化资源。矩阵涉及集中投入、发展、避免某些组合、合并、重新调整、出售退出等；原格位见P73。

5.4 组合管理的量与质（P74—77）

量的管理：增量与减量。增量途径为自创、并购、联盟、延伸；减量适用于品牌数量超过资源、绩效与管理能力的情况。

课件比较表〔速度/控制/投资〕：自创〔慢/高/中〕；并购〔快/中/高〕；联盟〔中/低/低〕；延伸〔快/高/中〕。

质的管理五关系：母子品牌、多品牌、外来与自有品牌、受托与托权品牌、全球与区域品牌。母品牌提供优质形象，子品牌表达特性；多品牌合理定位、竞争互补；外来品牌明确市场进入或防御角色；受托与托权明确展示关系；全球区域合理搭配。

第6章｜品牌延伸

6.1 定义、分类、收益与风险（P16—26）

狭义延伸指原品牌进入新品类；广义包含同类产品线、异类产品及新细分市场。本课采用广义观点。母品牌为实施延伸的现有品牌，延伸产品是新产品；延伸中新增并与原品牌并用的名称可形成子品牌。

所有权分类：公司内延伸、公司外延伸（品牌授权）。

产品关系分类：产品线延伸〔换代、水平、垂直〕；产品类别延伸〔连续性、非连续性〕。水平为同档不同用途/人群；垂直为更高或更低档；连续性依托技术共通性；非连续性跨越技术和行业限制。

命名分类：单一品牌延伸〔同名〕；主副品牌延伸〔相同主品牌＋不同副品牌〕；亲族品牌延伸〔部分名称共通，如“麦”系列〕。

四作用：节省推广费用、提高认知；多元选择；提升内涵；规避部分经营风险。

六风险：损害原形象、个性稀释、心理冲突、株连、跷跷板、挤占原产品销量。高端向下延伸与高度品类绑定须谨慎。

跷跷板：新类别增长同时原类别地位被竞争者占领；挤占：延伸产品替代自家原产品；株连：某一产品失败损害其他产品声誉；三个机制不同。

6.2 成功因素与三个必背模型（P28—41）

强势母品牌是基础：高知名度、品质认知、忠诚、积极丰富联想。

相似性两类：产品相关〔技术/资源可转移、互补、替代〕；非产品相关〔形象、象征意义等价值性〕。

外部与执行因素：新产品需求、竞争态势、企业支持力度。

Davidson范围模型四区：内核〔产品线〕、外核〔同类产品〕、延伸区域〔较远类别〕、禁区〔认知冲突〕。

卡普菲勒能力模型：品牌内涵从专有技术、利益、个性到价值观；内涵越抽象，技术差异跨度可能越大。技术型依赖技术迁移，利益型依赖同一利益，个性/价值观可跨较远类别，但不能据此认定必然成功。

边界模型两因素：核心品牌的功能性/表现性认知、延伸产品关联性。四关联方向：技术性、互补性、替代性、价值性。

高功能高表现：可探索四方向；高功能低表现：主要技术/互补/替代，不宜纯价值跨越；低功能高表现：优先价值，也可适当互补/替代；低功能低表现：延伸困难，有限互补/替代仍需测试。

6.3 延伸七步骤与双重评估（P32—44）

七步：选择母品牌 → 选择类型 → 测量消费者认知 → 识别候选对象/边界 → 评估选择产品 → 实施营销计划 → 评价成败。

认知研究：自由联想、投射为定性；李克特量表可量化认知与形象。

产品选择两问题：消费者接受程度；对母品牌正面、负面或无明显影响。

营销计划建立共同点，使资产迁移；处理命名、标志、产品特征和广告诉求的一致性。

成败两标准：延伸产品业绩、对母品牌资产影响。一级评估因素五项：相似度、品牌强势度、品牌认知度、品牌联想度、营销竞争力；课件提到15个二级指标但未列全，不能自行冒充课件补齐。

案例、必背清单与易错点

易错②水平≠垂直；连续性≠同一产品线，连续性类别延伸仍可进入新类别。

易错③有名不代表适合任何品类；消费者是否接受和对母品牌影响须分别测试。

易错④销售增长不等于延伸成功，不能忽略母品牌损害。

第7章｜品牌国际化

7.1 概念、意义、程度、动因和障碍（P11—18）

课件定义Global Branding强调统一名称、标志、包装、广告向不同国家地区扩张，以标准化形成规模经济和低成本。三基本含义：历史性；全球统一市场与差异化跨国经营相联系而不同；形式包括产品、资本、无形资产输出。

四意义：生产流通规模经济、降营销成本扩大影响、形象一贯、营销活动统一。

五程度指标：外销比重〔他国销量÷总销量〕、全球知名度、销售区域广度、资源国际化、人才国际化。

五动因：国内供给过剩/增速慢/竞争强、海外吸引力、规模降成本、分散风险、客户全球流动和趋同。

政治法律障碍五项：体制与涉外法规、政治格局、腐败、地方保护、东道国商业法律；社会文化障碍三项：语言文字、风俗习惯、行为规范。

7.2 六种进入战略：掌握资源、控制和风险（P20—32）

出口借外商渠道：投资少、借当地网络与信誉；但定价、促销和推广控制弱，协调或关系中断风险。

许可经营：合同授权名称与标识，收许可费；当地生产销售可降低部分贸易壁垒影响并适应需求；风险是控制不足、受许方形成技术或自有品牌后合作缩短。不能推成所有授权都能绕开所有监管。

战略联盟：交换/联合关键资源，分销售渠道联盟、品牌联盟；关键是资源互补与目标顾客匹配。

投资设厂：独立当地生产销售、控制与响应强、利于渠道伙伴；资本大、管理复杂、高风险，可能丧失低成本优势；须评资金、风险承受、跨文化能力。

并购或合资：借当地既有品牌和资源缩短认知与推广；仍需评估品牌契合和整合能力。

从贴牌到自主品牌：适合初期资源与经验较弱企业，逐步积累制造、技术、客户和品牌经营能力，如格兰仕。

7.3 四种经营战略与六步骤（P33—39）

标准全球化：尽量一致的全球营销与形象；模拟全球化：介于全球化与本土化；标准本土化：适应明显地方需求；体制决定的本土化：受法律制度约束进行调整。

课件对应约25%、27%、16%、32%，合计100%；其样本及适用范围未交代，作为原课件示例记忆，不能用作当前企业总体分布。

六步：重新定义品牌识别 → 选择国家/地区 → 接近细分目标市场 → 选择品牌架构 → 选择适合产品 → 构建全球营销活动。

核心价值、名称、标志须保持长期一致，同时产品与传播适应当地需求法规。选择国家不等于已经选择该国的目标顾客。

案例、必背清单与易错点

TCL：国际化进入与整合；格兰仕：世界工厂到世界品牌；吉利：当地人才、组织、设计、经营理念、本土认可；可口可乐印度：制度约束和并购。

必背：三含义、意义4、程度5、动因5、障碍2组、进入6、经营4、步骤6。

易错①出口额不是国际化程度唯一指标；当地品牌认知、资源和人才同样重要。

易错②进入战略回答“怎样进去”，经营战略回答“进去后怎样经营”。

易错③全球一致性不是各国完全照搬；本土化也不等于放弃核心识别。

易错④并购速度快不代表整合容易；贴牌能力也不等于自主品牌资产。

第8章｜品牌维护和危机管理

8.1 品牌维护与监测（P9—13）

品牌维护是应对环境变化，维护形象、地位和价值的一系列活动。

定性监测：少量非代表个案，座谈、深访，解释潜在原因动机，形成初步概念；定量监测：代表性样本，入户/街头定点等，量化并在抽样条件满足时推断总体。

三监测对象：消费者选择行为〔知名、美誉、忠诚、联想〕；竞争品牌；品牌市场表现。

老字号材料说明维护与更新必要性；课件历史统计不能作为当前老字号整体经营比例。

8.2 三类维护策略（P15—35）

自我维护：防伪打假、控制品牌机密、避免互相杀戮。

防伪按功能为保真/辨假；按领域为产品/标识/信息；按识别范围为公众明防/专业暗防/特殊防伪；按技术为物理、化学、生物、多学科、商标综合。

防伪应用三途径：独立开发、专业合作、购买已开发产品。打假需长期意识、人财物投入、组织机构。

保密三点：意识、限制技术参观考察、防内部泄密；避免互相杀戮包括恶性降价与攻击。

法律维护：及时注册取得权利、按期续展、独特设计减少仿冒；名称之外保护标志、包装、广告语，并考虑近似名、未来市场、相近行业、域名。

课件注册口径：申请在先、同日申请看使用先；有效期10年、可续展。P22“一商标一类”和P31“期满前6个月”是旧材料表述；通常现行续展办理窗口为期满前12个月、宽展6个月。复习保留旧表述及差异，实务以官方最新规定为准，不能将其混写为同一时期规则。

商标申请流程：申请书、图样、证明、费用；课件列中国商标网及标为“2026修正”的链接，这里只保留其来源记录，不据标题认定法律状态。

经营维护：质量保证与提升〔评估现状、跟踪质量要求、建高质量形象〕；六种更新〔产品、重定位、名称、标志、包装、传播/广告〕；建立品牌/客户档案，了解偏好与交易，改善开发推广、沟通与忠诚。

8.3 危机定义、五特征、内外原因（P37—49）

危机是突发内外原因造成形象损害、价值降低，使组织陷入危险困难。

五特征：突发、危害、冲击、关注、机遇。机遇指处理得当可能重建信任，不表示危机本身有利。

外部六原因：他人陷害、媒体报道、其他品牌牵连、代言人、宏观因素、自然灾害。课件广义自然灾害还包含非人力控制的变化。

内部四原因：错误决策、低水平管理、生产性错误、广告错误。定位错误、忽视变化、盲目扩张属于决策；质量数量技术服务属于生产性错误。

8.4 危机管理全过程（P51—57）

三阶段：预防 → 处理 → 恢复。

预防五项：全员危机意识、运营环节监控、信息监测、自我诊断、危机管理小组。

六处理原则：主动、快捷、诚意、真实、统一、全员。

四一般措施：成立小组控制蔓延、适当处理策略、危机沟通、坦诚真相；沟通需确定对象、时机、渠道。

恢复两方面：遗留问题〔内部总结组织沟通心理影响、外部后续通报与信任〕；滞后效应〔长期阴影和信心重建〕。

第9章｜品牌资产管理

9.1 概念、特征与五星模型（P8—23）

三视角：财务会计〔无形资产货币价值〕；市场品牌力〔市场表现与未来成长〕；消费者〔意义、认知和关系〕。

艾克定义：与名称符号相关的一组资产和负债，能够增加或减少产品服务给企业与顾客的价值。包含负向效应，不能只考虑正面资产。

四特征：价值性、无形性、波动性、积累性。

五星构成：知名度、品质认知、联想、忠诚、其他资产。

知名度四层〔低到高〕：无知名度 → 提示知名度 → 未提示知名度 → 第一提及知名度；价值在形成前提及弱化竞争影响。

品质认知是对客观质量的主观整体判断；四价值：购买理由、溢价、渠道谈判力、延伸力。

联想三层：属性、利益、态度；四价值：认知、差异、购买理由、延伸基础。

忠诚四类型/阶段：认知性〔知道优于他牌〕、情感性〔满意偏爱〕、意向性〔想再买〕、行为性〔实际行动并克服障碍〕；四价值：低营销成本、渠道谈判、吸引新客、缓和威胁。

其他资产包括专利、专有技术、商标等，如7X配方。

9.2 怎样建立四类消费者资产（P25—28）

知名度：有效广告〔创意、广告语、标志、持续重复〕、强势公关、口碑。

品质认知：高品质产品服务、展示品质、价格暗示、品质认证。

联想：选择属性与利益等关键因素，用包装、广告语、代言人、促销、公关传播。

忠诚：超越期望、客户关系管理〔消费者数据库、常客奖励、会员俱乐部〕。

9.3 财务评估：成本、股价、收益（P30—35）

历史成本法：累计品牌创建/购置投入，包括设计、广告、促销、研究开发、分销、注册等；优点直接，缺点不能反映现在价值。

重置成本法：品牌价值＝重置成本×成新率；重置成本＝账面原值×评估时物价指数÷购置时物价指数；成新率＝剩余年限÷〔已用年限＋剩余年限〕。百分比代入时转为小数。局限是重建同样品牌难以模拟。

股票价格法：A＝股价×总股数；B＝有形资产价值；C＝A−B为无形资产，再区分品牌、研发专利等非品牌、其他垄断因素。课件C1＝B×后面的贡献系数缺失，不能将残缺公式当完整公式；核心是识别品牌贡献，非把全部C当品牌。

收益现值法：分离品牌净收益、预测未来收益，再按贴现率折现累加。课件还提过去收益终值与未来收益现值之和，使用时必须统一估值时点，避免重复计入。理解公式：未来部分PV＝Σ〔品牌净收益t÷(1+r)^t〕，这是对折现机制的说明。

收益法四局限：外部影响不足、预测主观、贴现率和期限选择主观、超额收益在品牌与其他无形资产间难分。

9.4 市场评估：Interbrand与Financial World（P36—43）

课件Interbrand为改进收益现值法，逻辑是品牌带来稳定未来收益；简化公式V＝P×S。P为品牌收益，须剔除非品牌因素，课件要求过去3年利润加权；S为强度/收益倍数。

七因子权重：领导力25%、稳定力15%、市场力10%、国际力25%、趋势力10%、支持力10%、保护力5%，合计100%。

含义依次为市场地位、维持消费者特权、市场成长稳定、跨地理文化能力、行业方向影响、持续投资支持、合法及保护。

局限：收益预测不确定、行业市场适用限制、指标权重主观。课件评分0—100与“获利年限/倍数”的转换未充分交代；不能把0—100加权分直接默认成年数，也不能当作现代Interbrand完整官方方法。

Financial World借鉴并修改Interbrand，更依赖专家意见：销售额×行业利润率求营业利润，剔除非品牌利润、资本报酬与税收；最近两年利润按最近年权重为上一年2倍，即〔2×最近＋上一〕÷3；强度参考七因子，课件倍数范围6—20。

9.5 消费者评估：溢价、十要素、引擎（P44—50）

溢价＝同一可比产品有品牌愿付价格−无品牌愿付价格；课件价值＝差价×销量÷行业平均利润率。须通过调查/控制实验分离其他价格因素；优点直接识别额外支付，缺点偏当期、未充分体现长期。

十要素分五组：忠诚〔价格溢价/课件写价格优惠、满意度或忠诚〕；品质/领导〔感觉品质、领导或普及〕；联想/差异〔感觉价值、个性、组织联想〕；认知〔品牌认知〕；市场行为〔份额、市场价格及分销区域〕。共2＋2＋3＋1＋2＝10。

十要素综合消费者与市场，适合持续或专项研究，敏感但需按行业调整；“价格优惠”的表述不要误解成折扣越大资产越强。

引擎模型：硬性属性＝有形功能认知；软性属性＝情感利益。标准问卷和统计分解识别总体得分、子项贡献及真正驱动因素；购买行为只能体现结果，未必揭示原因。问卷需行业调整。

BPTO品牌抵补模型在分类表作为代表名称出现，课件未展开程序，保留名称与所属财务＋消费者要素类别，不编造本课未讲步骤。

9.6 课件计算题：先写口径再计算（P54）

题给销售额500亿元、行业利润率22%、资本产出率45%、税率15%、无品牌资本“净利润”8%、S＝20；题中“餐饮业”与娃哈哈对象不一致，属题干口径问题。

假设资本产出率＝销售额÷投入资本，则投入资本K＝500÷0.45＝1111.111亿元；营业利润＝500×0.22＝110亿元；税后营业利润＝110×0.85＝93.5亿元。

若8%按题面“净利润”理解为税后正常资本回报率，正常回报＝K×0.08＝88.889亿元；品牌净收益P＝93.5−88.889＝4.611亿元；V＝4.611×20＝92.222亿元。

若教师将8%定义为税前资本报酬，应先减资本回报再计税：P＝(110−88.889)×0.85＝17.944亿元；V＝358.889亿元。两答案来自不同税口径；不能省略假设，也不能把案例数值当实际品牌估值。

自测：七因子权重能否脱稿写出并合计100%；强度给定时能否区分营业利润、正常资本回报、品牌收益；每个百分比是否转为小数。

第10章｜产品（课程总目录称“产品与品牌”）

10.1 产品整体概念和产品文化（P5—7）

产品是市场上可供注意、获取、使用并满足需求欲望的任何东西，包括实体、服务、人、组织、地名、思想。

五层：核心产品〔基本利益〕→ 一般产品〔利益转成具体基本形态〕→ 期望产品〔通常期待的属性条件〕→ 附加产品〔超出期待的现有利益〕→ 潜在产品〔未来可能的附加和转化〕。

理解例（非课件原例）：酒店核心是休息；一般是房间床具；期望是清洁安静；附加是超预期服务；潜在是未来体验升级。某项服务属于期望还是附加随顾客标准和时间变化。

产品文化以产品为载体，统一产品价值、使用价值、文化附加值；三层涉及整体理解形象、质量与质量意识、设计中的文化。

核心产品文化通过形式产品文化演绎；质量、功能、特征、包装、品牌文化互相关联。形式不仅是外包装，也包括内在质量功能和外在款式包装品牌。

10.2 生产方式、设计、形象与识别（P8—15）

OEM：原始设备制造/贴牌生产，采购方提供品牌授权等，制造方生产，采购方负责销售。

ODM：原始设计制造，受托方提供研发设计制造等服务，采购方以其品牌负责市场销售。

OBM：自有品牌生产/经营，自建品牌面向市场，设计、采购、生产、销售由自身完成或管理外包。P10解释开头“ODM”应为“OBM”。

产品设计是从设计任务书到结构确定的技术准备和管理，是开发的重要环节。

产品形象PI是内在品质与外在视觉的统一；三方面：视觉、品质、社会形象；带来总体印象、心智特殊地位、功能情感利益。

形象设计是围绕企业整体目标，以产品设计为核心，协调理念、技术、材料、造型、色彩、工艺、包装、运输、展示、营销广告。

产品识别是有意识、有计划用造型等使用户形成一致认同；外部视觉识别〔形态、材质、色彩、UI界面〕；内部个性识别〔体验、文化、情感、价值观、信仰〕。

三意义：帮助识别品牌；巩固提升公众形象；形成附加价值并支持周边/子品牌。

必背清单与易错点

必背：产品范围6、产品五层、文化定义及结构、OEM/ODM/OBM、PI三形象、识别2类及要素、识别3意义。

易错①核心产品是消费者买的利益，不是最重要零件；期望是常规，附加是超预期，潜在是未来。

易错②产品文化不是只在包装添加故事；质量、功能和设计同样承载文化。

易错③ODM增加设计研发，OBM增加自主品牌市场经营；自有品牌不要求绝对不外包制造。

易错④产品识别不是只贴Logo，材质、造型、界面、体验均能承载识别。

易错⑤产品形象、产品设计、产品识别是不同概念：总体印象、开发活动、形成统一认同的系统。
